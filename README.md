# Proyecto-IPVG-Gaming
iPVG Gaming Biobío — Plataforma eSports

Plataforma web oficial del circuito de eSports del Instituto Profesional Virginio Gómez . Diseñada para centralizar la comunidad competitiva estudiantil 

---

Características Principales

Visualización de Disciplinas Activas: Información en tiempo real sobre los torneos vigentes (Valorant, Fortnite, League of Legends, EA Sports FC).
Sistema de Inscripciones Interactivo: Formulario modal integrado para que los equipos y jugadores se registren seleccionando su sede y disciplina.
Reglamento Oficial: Ventana flotante con las normativas, formato de partidas.
Diseño Responsivo y Moderno: Interfaz adaptada para PC de escritorio con una estética gamer/oscura optimizada.

---

Tecnologías Utilizadas

Este proyecto fue desarrollado utilizando tecnologías web nativas ligeras y de alta velocidad:

HTML5: Estructura semántica moderna de la plataforma.
CSS3: Estilos personalizados, diseño adaptable (Grid/Flexbox) y efectos visuales oscuros.
JavaScript (Vanilla):** Lógica interactiva para la apertura de modales, gestión dinámica de formularios y confirmaciones de inscripción.
